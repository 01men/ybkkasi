# 协议键中文对照总表

> 任务编号：R10（REFACTOR-2026-10-13 阶段 2 · 汉化收敛）
> 编制日期：2026-10-13
> 依据：《榕器（ybkk-AIOS）全局重构方案 · 全盘对照 paperclip》§三.2（协议层：保留 ASCII 键 + 中文对照）与 §五 阶段 2「R10 对照总表」条目
> 用途：本仓汉化方略为「表现层全中文、协议层保留 ASCII 键」。事件名、权限点、错误原因码、环境变量、浏览器存储键、API 信封字段是跨系统契约（RQ-DSH 定制轨、MCP 客户端、selftest 断言、dsh 宿主校验均依赖），**不随汉化改写**。本表为这些键的唯一中文对照文档：开发者在中文文档里可查明每个键的含义、产生位置与用途。新增协议键时必须同步本表（selftest 可按「完备性口径」小节给出的 grep 模式做清点断言）。

阅读约定：

- 表内「键」一律保留 ASCII 原样；「出处」为简写路径（相对 `packages/` 或仓根）。
- 带插值的键以模板形式给出（如 `heng_ops_token@<connectionId>`、`panel_channel_<deptId>`）。
- 「事件名」一节中 `插件命名空间` 指第三方插件事件必须收敛的 `plugin:<id>:<event>` 前缀；平台保留命名空间见 bus.ts 的 `PLATFORM_RESERVED_PREFIXES`（iam./authn./oidc./mcp./nas./audit./skill./agent./app./usage./billing./model./market./developer./wallet./platform./approval./connector./console./connect./behavior./panel./scenegraph./dingtalk-bridge./modelgw./flow./resource.）。当前仓内全部插件均为平台内置插件（source 为平台内部），尚无第三方 `plugin:<id>:` 前缀事件实例。
